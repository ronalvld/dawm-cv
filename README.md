# Currículum Vitae – DAWM

## Descripción
Este proyecto consiste en una página web personal que presenta mi currículum vitae de forma digital. Fue desarrollado durante las clases de la asignatura Desarrollo de Aplicaciones Web y Móviles (DAWM), aplicando los conocimientos adquiridos.

**Página web:** https://ronalvld.github.io/dawm-cv/

## Tecnologías utilizadas

- **HTML5:** utilizado para construir la estructura de la página y organizar su contenido.
- **CSS3:** utilizado para personalizar el diseño, los colores, las fuentes y la distribución de los elementos.

## Herramientas utilizadas

- **Visual Studio Code:** editor utilizado para escribir y modificar el código.
- **Git:** herramienta de control de versiones.
- **GitHub:** plataforma utilizada para almacenar el código fuente.
- **GitHub Pages:** servicio utilizado para publicar la página web.

## Aplicación de los conocimientos

Durante las clases se aplicaron los conocimientos de HTML5 y CSS3 para desarrollar la estructura y el diseño visual del currículum. También se utilizaron Git y GitHub para gestionar el proyecto y GitHub Pages para publicarlo en Internet.
